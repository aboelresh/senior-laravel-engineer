# الدرس التاسع: التنقل في Linux بثقة

## مصطلحات مهم تعرفها قبل ما نبدأ

| المصطلح | المعنى |
|---------|--------|
| pwd — Print Working Directory | يعرض مسار المجلد الحالي |
| cd — Change Directory | الانتقال بين المجلدات |
| ls — List | عرض محتويات المجلد |
| Absolute Path | مسار كامل يبدأ من الـ Root مثل `/var/www` |
| Relative Path | مسار نسبي يبدأ من مجلدك الحالي مثل `myapp` |
| Hidden Files | ملفات تبدأ بنقطة مثل `.env` — لا تظهر في `ls` العادي |
| find | أمر البحث عن الملفات والمجلدات |
| which | يعرض مسار البرنامج التنفيذي |
| df — Disk Free | يعرض مساحة الـ Disk |
| du — Disk Usage | يعرض حجم المجلد |
| tail -f | متابعة ملف في الوقت الفعلي |
| VFS — Virtual File System | طبقة تجريد في الـ Kernel تُوحّد التعامل مع أنظمة الملفات المختلفة |

## شرح المفاهيم

### أولاً: أين أنا؟ — pwd

```bash
pwd
```

المخرجات:
```
/home/ahmed
```

يعني: أنت حالياً في مجلد `ahmed` داخل مجلد `home`.

ما يحدث خلف الكواليس: `pwd` تستدعي System Call هي `getcwd()`. الـ Kernel يقرأ من هيكل الـ VFS الموقع الحالي للـ Process ويُعيده للـ Shell.

---

### ثانياً: الانتقال بين المجلدات — cd

```bash
# الذهاب لمجلد محدد (Absolute Path)
cd /var/www

# الذهاب لمجلد بداخل مجلدك الحالي (Relative Path)
cd myapp

# الذهاب للـ Home Directory
cd ~
# أو ببساطة
cd

# الذهاب للمجلد الأعلى
cd ..

# الذهاب لمجلدين للأعلى
cd ../..

# الذهاب للمجلد السابق
cd -
```

**cd - :**

```bash
cd /var/www/myapp
cd /etc/nginx
cd -
# يعود لـ /var/www/myapp فوراً
```

مثل زر Back في المتصفح. مفيد جداً عند التنقل بين مجلدين بعيدين.

---

### ثالثاً: ماذا يوجد هنا؟ — ls

```bash
# عرض محتويات المجلد الحالي
ls

# عرض محتويات مجلد محدد
ls /var/www

# عرض الملفات المخفية أيضاً (تبدأ بنقطة)
ls -a

# عرض تفاصيل كاملة
ls -l

# الأكثر استخداماً — تفاصيل + ملفات مخفية
ls -la

# ترتيب حسب وقت التعديل (الأحدث أولاً)
ls -lt

# عرض الأحجام بشكل مقروء (K, M, G)
ls -lh
```

**فهم مخرجات ls -la:**

```
drwxr-xr-x  3  www-data  www-data  4096  Jan 15 10:30  storage
│││││││││    │  │         │         │     │             │
│││││││││    │  │         │         │     │             └─ اسم الملف
│││││││││    │  │         │         │     └─ تاريخ التعديل
│││││││││    │  │         │         └─ الحجم بالـ bytes
│││││││││    │  │         └─ اسم المجموعة (Group)
│││││││││    │  └─ اسم المالك (Owner)
│││││││││    └─ عدد الـ Hard Links
│││└──────── صلاحيات المجموعة (r-x = قراءة وتنفيذ)
││└───────── صلاحيات الآخرين (r-x = قراءة وتنفيذ)
│└────────── صلاحيات المالك (rwx = قراءة وكتابة وتنفيذ)
└─────────── نوع الملف (d = Directory, - = File, l = Link)
```

### رابعاً: البحث عن الملفات — find

```bash
# البحث عن ملف باسمه
find /var/www -name "index.php"

# البحث عن كل ملفات PHP
find /var/www/myapp -name "*.php"

# البحث عن مجلدات فقط
find /var/www -type d

# البحث عن ملفات فقط
find /var/www -type f

# البحث عن ملفات أكبر من 100 MB
find /var/log -size +100M

# البحث عن ملفات أقدم من 30 يوم
find /var/log -name "*.log" -mtime +30

# البحث وحذف الملفات المؤقتة القديمة
find /tmp -mtime +7 -delete
```

**مثال عملي في Laravel:**

```bash
# إيجاد كل ملفات الـ .env في المشروع
find /var/www/myapp -name ".env"

# إيجاد ملفات Log كبيرة
find /var/www/myapp/storage/logs -size +50M

# إيجاد ملفات عُدّلت اليوم
find /var/www/myapp -mtime 0 -name "*.php"
```

**which و whereis — أين يوجد هذا البرنامج؟**

```bash
which php
# /usr/bin/php

which nginx
# /usr/sbin/nginx

whereis php
# php: /usr/bin/php /usr/lib/php /etc/php /usr/share/php
# يعرض الملف التنفيذي + الـ Libraries + الإعدادات
```

### خامساً: معرفة الحجم والمساحة

**df — مساحة القرص:**

```bash
df -h
```

المخرجات:
```
Filesystem      Size  Used Avail Use% Mounted on
/dev/sda1        50G   20G   28G  42% /
tmpfs           2.0G     0  2.0G   0% /dev/shm
```

أهم عمود هو `Use%`. إذا تجاوز 85% تحذير، إذا وصل 95% خطر.

**du — حجم المجلد:**

```bash
# حجم مجلد محدد
du -sh /var/www/myapp

# حجم كل مجلد فرعي
du -sh /var/www/myapp/*

# أكبر 10 ملفات أو مجلدات
du -sh /var/log/* | sort -rh | head -10
```

---

### سادساً: عرض محتوى الملفات

```bash
# عرض الملف كاملاً — للملفات الصغيرة
cat /var/www/myapp/.env

# عرض تفاعلي للملفات الكبيرة
less /var/log/nginx/error.log

# آخر 10 سطور
tail /var/log/nginx/error.log

# متابعة الملف في الوقت الفعلي — الأكثر استخداماً في Production
tail -f /var/www/myapp/storage/logs/laravel.log

# أول 20 سطراً
head -n 20 /etc/nginx/nginx.conf
```

**داخل less:**
```
Space     ← الصفحة التالية
b         ← الصفحة السابقة
/keyword  ← البحث عن كلمة
n         ← التالي في البحث
G         ← آخر الملف
g         ← أول الملف
q         ← الخروج
```

`tail -f` هو الأمر الأكثر استخداماً عند تشخيص مشاكل Production. يُبقي الملف مفتوحاً ويعرض أي سطر جديد فور كتابته.

### سابعاً: معلومات النظام السريعة

```bash
# نسخة نظام التشغيل
cat /etc/os-release

# نسخة الـ Kernel
uname -r

# وقت تشغيل السيرفر

# استهلاك الذاكرة
free -h

# معلومات المعالج
cat /proc/cpuinfo | grep "model name" | head -1

# عدد الـ CPU Cores

```

## التشبيه الحياتي

التنقل في Linux مثل التنقل في مبنى:

```
pwd    ← تنظر للافتة على الباب (أين أنا؟)
cd     ← تمشي لغرفة أخرى
ls     ← تنظر لما في الغرفة
find   ← تبحث عن شيء في المبنى كله
df     ← تتحقق من سعة المستودع
du     ← تزن الأشياء في غرفة معينة
tail -f← تجلس عند باب وتراقب من يدخل ويخرج
```

## أسئلة المقابلات

**س: كيف تراقب Laravel Logs في الوقت الفعلي على السيرفر؟**

باستخدام `tail -f /var/www/myapp/storage/logs/laravel.log`. هذا الأمر يُبقي الملف مفتوحاً ويعرض أي سطر جديد فور كتابته مما يُتيح مراقبة الأخطاء أثناء حدوثها.

**س: السيرفر بطيء فجأة. ما الأوامر التي تستخدمها؟**

أبدأ بـ `df -h` للتحقق من مساحة الـ Disk، ثم `free -h` لمعرفة استهلاك RAM، ثم `uptime` لمعرفة مدة التشغيل ومتوسط الحمل. بعدها أنتقل لأوامر الـ Processes.

---

## الأسئلة والإجابات

### المستوى الأول

**السؤال الأول:** ما الفرق بين `ls -l` و `ls -la`؟

`ls -l` يعرض الملفات والمجلدات بالتفاصيل. `ls -la` يضيف الملفات المخفية، وهي التي تبدأ بنقطة. إذن `a` = all.

---

**السؤال الثاني:** ما الفرق بين `cat` و `less` و `tail`؟

- `cat` → عرض الملف كاملاً، مناسب للملفات الصغيرة.
- `less` → قراءة ملف كبير بشكل تفاعلي والتنقل داخله والبحث فيه.
- `tail` → عرض آخر سطور الملف، ممتاز للـ Logs.
- `tail -f` → متابعة الـ Log لحظياً.

مثال:
```bash
tail -f /var/www/myapp/storage/logs/laravel.log
```

---

**السؤال الثالث:** ماذا يفعل `cd -`؟

يرجعك إلى المجلد السابق. مثلاً:

```bash
cd /var/www
cd /etc/nginx
cd -
# ترجع إلى /var/www
```

فكر فيه كأنه زر Back.

---

### المستوى الثاني

**السؤال الرابع:** اكتب أمراً يعرض أكبر 5 ملفات Log في `/var/log`.

```bash
find /var/log -type f -name "*.log" -exec du -h {} + | sort -hr | head -5
```

الفكرة: `find` يبحث → `du` يجيب الحجم → `sort` يرتب → `head -5` يأخذ أكبر خمسة.

---

**السؤال الخامس:** كيف تجد كل ملفات `.env` في مجلد `/var/www` وما فائدة ذلك أمنياً؟

```bash
find /var/www -name ".env"
```

أمنياً، ملفات `.env` مهمة لأنها قد تحتوي على Database passwords وAPI keys وApplication secrets. معرفتها مهم أثناء الـ Security Audit، لكن لا ينبغي عرض محتواها أو تسريبها.

---

### المستوى الثالث

**السؤال السادس:** السيرفر يُعطي خطأ "No space left on device". اكتب تسلسل الأوامر.

أبدأ بالتشخيص:

```bash
df -h
```

أعرف أي Filesystem ممتلئ. بعدها:

```bash
du -sh /var/*
```

أحدد أي Directory يستهلك المساحة. لو المشكلة في `/var/log` مثلاً:

```bash
du -sh /var/log/*
```

ثم أبحث عن الملفات الكبيرة:

```bash
find /var/log -type f -size +100M
```

بعد تحديد السبب أعالج الملفات أو الـ Logs المناسبة ثم أتحقق مرة أخرى:

```bash
df -h
```

المهم هنا: لا نحذف عشوائياً لمجرد إن الـ Disk مليان.

---

**السؤال السابع:** ما الفرق بين `-name` و `-iname`؟

```bash
find /var/www -name "*.php"
```

حساس لحالة الأحرف. أما:

```bash
find /var/www -iname "*.php"
```

غير حساس لحالة الأحرف. يعني `test.php` و `test.PHP`:
- `-name` → الثاني لا يطابق.
- `-iname` → الاثنان يطابقان.

---

### المستوى الرابع

**السؤال الثامن:** ملفات PHP المعدّلة خلال آخر 24 ساعة، مرتبة حسب وقت التعديل.

```bash
find /var/www/myapp -type f -name "*.php" -mmin -1440 -printf '%T@ %p\n' | sort -nr
```

`-mmin -1440` لأن 24 ساعة = 1440 دقيقة. و`%T@` يعطي وقت التعديل بصيغة رقمية مما يُتيح `sort -nr` للترتيب من الأحدث للأقدم.

## الاختبار السريع

**السؤال 1:** كيف تعرض محتويات المجلد الحالي بما فيها الملفات المخفية مع التفاصيل الكاملة؟

```bash
ls -la
```

---

**السؤال 2:** `cd ..` تأخذك للـ Root Directory. صح أم خطأ؟

خطأ. `cd ..` تأخذك مجلداً واحداً للأعلى. أما الوصول للـ Root:

```bash
cd /
```

---

**السؤال 3:** اقرأ المخرجات:

```
-rw-r--r--  1  www-data  www-data  2048  Jan 15  .env
```

```
-rw-r--r--
 │││ │││ │││
 │││ │││ └── Others: r-- (قراءة فقط)
 │││ └────── Group:  r-- (قراءة فقط)
 └────────── Owner:  rw- (قراءة وكتابة)
```

المالك فقط يستطيع التعديل. المجموعة والآخرون يستطيعون القراءة فقط.

---

**السؤال 4:** Laravel بدأ يعطي أخطاء منذ 10 دقائق. اكتب الأمر الأول.

```bash
tail -f /var/www/myapp/storage/logs/laravel.log
```

---

**السؤال 5:** كيف تجد كل الملفات في `/tmp` التي مضى عليها أكثر من 7 أيام؟

```bash
find /tmp -type f -mtime +7
```

`-mtime +7` تعني ملفات أقدم من 7 أيام.
