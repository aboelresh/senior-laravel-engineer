## عن هذا الريبو

هذا الريبو هو توثيق كامل لرحلة تعلمي كـ Backend Engineer.  
كل توبيك بدرسه بكتب ملف `md` فيه شرح وتلخيص وأمثلة كود — وكل module بيخلص بـ mini project حقيقي.

**الهدف:** بناء عقل هندسي صحيح، مش بس حفظ syntax.
